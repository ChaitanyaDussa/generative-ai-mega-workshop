# 🤖 Generative AI Mega Workshop 2.0

### Exploring AI-Powered Creativity, Design & MVP Development

A collection of projects, experiments, and insights from the **Generative AI Mega Workshop 2.0 by NxtWave**. 💡

This workshop explored how modern AI tools can accelerate the journey from an idea to a creative output — from building user personas and designing logos to generating videos and creating Minimum Viable Products (MVPs).

The experience provided hands-on exposure to AI-powered creativity, prompt-driven workflows, and rapid product development.

## 🚀 Workshop Highlights

- 🧑‍💻 **User Persona Creation** — Explore AI-assisted approaches to understanding target audiences.
- 🎨 **AI Logo Design** — Generate branding concepts using Sologo AI.
- 🎥 **AI Video Creation** — Experiment with Gamma AI to transform ideas into visual presentations and video content.
- 🌐 **MVP Development** — Explore rapid website and product creation using Wegic.
- 💡 **AI Tool Exploration** — Understand how different AI tools can support creative and product-building workflows.
